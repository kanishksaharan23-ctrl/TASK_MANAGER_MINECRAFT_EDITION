# Task Manager: Minecraft Edition ⛏️

A campus micro-task marketplace designed for student-to-student help[cite: 1]. Students can post small tasks (e.g., collecting a parcel) with clear rewards, while others claim and complete them[cite: 1].

### 🚀 MVP Overview
*   **The Problem:** Finding reliable help for quick campus tasks is difficult[cite: 1].
*   **The Solution:** A centralized task board to post, browse, claim, and track tasks[cite: 1].
*   **UI/UX:** A custom Minecraft-inspired pixel interface[cite: 1]. 

### 🛠️ Tech Stack & Build
This is currently a standalone frontend prototype tested directly in the browser[cite: 1]:
*   **HTML:** Page structure, task cards, and forms[cite: 1].
*   **CSS:** Layout, colors, and the Minecraft pixel-art styling[cite: 1].
*   **JavaScript:** Core logic for posting, filtering, claiming tasks, and updating dashboard counters[cite: 1].
